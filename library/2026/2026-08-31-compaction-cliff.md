# The Compaction Cliff in Long-Running AI Agent Memory

## Notes

Type-blind compaction treats safety rules like episodic logs. Claude Code /compact on Sonnet 4.6 keeps 53% of safety rules after one round and 10% after five. Knowledge Triage classifies items (constraint, procedural, belief, preference, episodic) and routes each type through its own retention policy. TypeCompact holds ~96% safety-rule recall over five rounds.

# ECLIPSE: Self-Evolving Stealthy Prompt Injection Attack against Long-Horizon Agentic Systems

## Notes

Stealthy multi-stage prompt injection for long-horizon agents (Codex/Claude Code–class): synthesizes a verified tool-chain in a sandbox, then steers the target via Static Workflow Encoding in tool descriptions plus Dynamic Trajectory Correction. LASE-Bench: 120 malicious tasks, 96.7% need ≥5 tool calls. Up to 96.7% ASR undefended, 69.2% under a common safety filter (+27.5 pp vs strongest baseline defended).

# ECLIPSE: Self-Evolving Stealthy Prompt Injection Attack against Long-Horizon Agentic Systems

## Notes

Self-evolving stealthy prompt injection for long-horizon agents (Codex / Claude Code–class). Combines direct user-prompt injection with indirect tool-side injection: Stealthy Attack Trajectory Synthesis (sandbox-verified tool chains rendered as natural one-shot prompts) plus Tool-Chain Steering (Static Workflow Encoding in tool descriptions + Dynamic Trajectory Correction at runtime). Introduces LASE-Bench (120 malicious tasks, 198 tools; 96.7% ≥5 tool calls). Up to 96.7% ASR undefended and 69.2% under a common safety filter (+27.5 pp vs strongest baseline defended). Existing defenses do not reliably stop it.

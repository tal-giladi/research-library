## Engineering blogs

### commit-rewriter 0.1
https://simonwillison.net/2026/Sep/14/commit-rewriter/

Willison ships commit-rewriter 0.1, a small Python web app (run via `uvx commit-rewriter [path]`) for rewriting git commit messages before public release. He built it while preparing the Datasette security releases: agent-authored commits were full of coding-agent scaffolding and private-repo issue IDs that were unfit to publish. The UI lets you edit messages across a commit range; on submit it snapshots the current repo state onto a timestamped branch (so you can revert), then rewrites every commit from the first edit through HEAD. Operational note for Tal’s agent-coding lane: treat agent commit text as draft provenance that needs a deliberate publish-gate rewrite before open source or security advisories—don’t ship raw agent trajectories into public history.

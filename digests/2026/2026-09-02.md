## LLM security

- **What's in Your Agent's Context? Context Privilege Escalation Attacks against AI Agent Harnesses** — First systematic look at how real coding-agent harnesses assemble context from mixed sources, and how that assembly itself becomes an attack surface. The authors define MessageRole Context Privilege Escalation (M-CPE), where low-privilege attacker content is promoted into a higher-privileged message role, and Cross-Scope Context Privilege Escalation (X-CPE), where attacker content persists past the scope it was introduced in. They audit against 12 real-world harnesses including Claude Code and Codex-class stacks. Reported consequences include full agent compromise, remote code execution, denial of service, and manipulated tool or skill invocations. Soft keyword miss on sources.yml, but this is the highest-priority security paper in the window for harness and agent-security work—include even though the filter did not catch “prompt injection” / “jailbreak” phrasing. https://arxiv.org/abs/2609.01222

- **HiveTraceGuard-Pro: A Compact Generative Guardrail for Prompt Injection, Jailbreaks, and Adversarial Obfuscation** — A 0.6B generative guardrail (LoRA on Qwen3-0.6B) aimed at prompt injection, jailbreaks, and obfuscation, bilingual Russian/English, with a binary safe/unsafe decision on the final target turn. Training pairs harmful and benign domain counterparts and applies eight obfuscation transforms to both labels so the guard sees disguised attacks and disguised benign text. In one harness versus 34 other guards across 19 benchmark groups, aggregate key score is 0.7432 (behind two higher scorers at 0.7641 / 0.7552); on 16 public groups alone, 0.7153 with four suite guards higher. Strengths called out: best clean Russian robustness combined-F1 (0.88) and Russian prompt-injection recall (0.999) among a 15-model comparison, with caveats that ≥27.1% of that PI set overlaps training and some response results used a legacy serialization path. Median latency 14.3 ms (lowest in that run); suite FPR 0.268, FNR 0.156. Merged weights released Apache-2.0; corpus and eval code remain internal. https://arxiv.org/abs/2609.01046

- **Cloudflare Adaptive Intelligence: raising the cost of AI-driven attacks** — Cloudflare launched Adaptive Intelligence, a continuous detection engine that learns from live traffic (the company claims analysis of more than a trillion web visits per day) and generates rules on the fly so automated attacks become slower and more expensive. The product pitches always-on retraining (no wait for scheduled rule packs), better catch of low-and-slow credential stuffing and scraping, human-vs-bot signals via Cloudflare Precursor behavioral verification, and autonomous defense upgrades with zero downtime. Deep View situates the launch against frontier models’ rising cyber capabilities and a coalition letter (including Cloudflare) urging stronger cyber defenses. For agent-security readers: this is the defensive counterpart to agentic offense—moving-target defenses that treat AI-cheap attack volume as an economics problem. https://www.thedeepview.com/articles/how-cloudflare-s-new-ai-tool-hits-hackers-in-the-wallet

## Agent memory / context

- **MutMem-V2: Cryptographically Authorized Mutation in Persistent Agent Memory** — Completes the portable verification and clean-install story for cryptographically authorized mutation of persistent agent memory, without a second memory engine. It specifies canonical bytes, domain-separated object/bundle commitments, recall-evidence membership and ordering, trust anchors, identity epochs, revocation, authorization, receipts, ordered disclosure, and three mutation terminal types. The release includes 18 versioned object schemas, 39 recall vectors, 15 mutation vectors, and 37 closed recall failure reasons. Independent Node and Python implementations agree on verdict and primary reason for all 72 structural/cryptographic terminals; a production-conformance corpus agrees on 42/42 cases across 28 required classes. Authors explicitly limit claims to portable integrity, authorization, traceability, conformance, and reproducibility—not semantic truth or universal robustness. A concrete integrity/provenance contract for long-lived agent memory. https://arxiv.org/abs/2609.01235

- **MemoryWalker: Stop Training Agents on Contexts They Never Saw** — Production harnesses (Claude Code, Qwen-Agent and peers) compress context during rollout, so training under compression makes the learning object a tree rather than a sequence. Naive linearizations either leak “time-travel” (rightmost path) or mismatch train versus inference (DFS replay). Exact fixes proposed: LogitTree (K+1 backwards) and a packed 4D attention mask with a custom kernel plus white-box eviction records. SDCC is a single-backward variational relaxation using stop-gradient teacher KL at each eviction, with an O(√ε_KL) bound on the train–deploy total-variation gap, and it works for black-box harnesses too. On seven web-search benchmarks with TC-RAG, AgentFold, MemexRL, Claude Code, and OpenCode, exact methods stay at the no-compression floor; SDCC closes much of the gap with lower logit drift and higher rollout rewards. Soft keyword miss, but central to agent memory and harness context compression. https://arxiv.org/abs/2609.00865

- **Clipto: local-first AI memory over videos, meetings, and docs** — Clipto positions itself as a local AI memory layer over a user’s existing media—videos, images, meetings, voice memos, documents, bookmarks—so you search by describing moments rather than filenames. Processing is local-first (cloud optional); Mac needs Apple silicon M1+ with 16GB+, Windows 12GB+ RAM; also iOS/Android/web paths plus MCP and Premiere/DaVinci plugins. Product framing: capture → understand/connect → reuse via search, summaries, editing clip locate, research evidence, an agent that answers with memory, and insight surfacing—with answers traceable to person/moment/timestamp. Explicitly advertises Memory usable from Claude, ChatGPT, Cursor, or Clipto’s own agent over MCP. Superhuman reports a fresh raise: $15M at a $250M valuation. Personal corpus as durable tool-backed memory rather than chat history alone. https://www.clipto.com/

- **Compile, Don't Memorize: A Context Compilation Architecture (CCA) for In-Context Learning** — Argues that read-and-reason in-context learning fails structurally on rule-dense contexts: strong open models pass only 12–16% when graded against every context detail. CCA compiles prose context once into a typed intermediate representation with fixed slots (must_do / must_not / conditional rules, output_spec, available_tools, data_profile), then runs executable verifiers and a violation-gated correction loop. On CL-bench (1,899 tasks × 4 open base models), it beats vanilla and two long-context baselines (ReadAgent-P, Ctx2Skill) on every base model. Kimi K2.5 rises from 15.4% to 21.4%, with gains concentrated on rule-dense subcategories. Soft keyword match—brief but on-theme as a harness pattern for context management rather than “memorize the whole prompt.” https://arxiv.org/abs/2609.00759

## Agent harness

- **Explore More, Drift Less (CANOPY): Outcome-Only RL Can Suffice for Long-Horizon Interactive Agents** — Argues the supposed ceiling of outcome-only RL for small open LLM agents is an artifact of signal starvation and policy drift, not a need for denser rewards or elaborate scaffolding. CANOPY scales same-task exploration until mixed success/failure groups reappear, keeps updates on-policy and KL-anchored, and confines gradients to the agent’s own action tokens. On AppWorld, Qwen3-14B trained only via environment interaction topped the public leaderboard (Feb 2026; Test-Normal TGC 86.9, Test-Challenge 67.6) without task-specific SFT or auxiliary credit. The same design lifts Qwen3.5-9B on SWE-bench Verified by 16.6 points. Authors plan to release the training stack (SignalCoverageRL). Strong harness/training takeaway: exploration coverage and on-policy anchoring can beat add-on memory or multi-agent scaffolding. https://arxiv.org/abs/2609.01245

- **HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?** — Benchmark that evaluates whether models can create and evolve their own agent harness, not just solve tasks inside a fixed one. Creation: from a minimal seed plus a few cases, build a complete execution system. Evolution: revise that harness from downstream feedback to improve held-out performance. Scores capability (task success) and efficiency (execution-token cost) across six creator LLMs, four domains, and five benchmarks (2,207 unique downstream instances) with hidden eval tasks. Generated harnesses lag mature human references on code and search/research, but match or exceed on writing and ML experimentation; costs vary widely. Evolution gains are unstable and transfer only partially; benefits depend strongly on the runtime model executing the harness. Soft keyword miss (“agent harness” vs sources.yml “agent framework”), squarely on-topic. https://arxiv.org/abs/2609.01437

- **Harness-of-Harness: Multi-Day Autonomous Software Development with Continual Improvement** — HoH wraps existing coding-agent harnesses in iterative planning–coding–testing loops that balance repair versus capability growth and verifiable increments. Separates implementation-time testing from independent evaluation; progressively exposes deliverables and role tools/skills; maintains versioned project history. On GameCraft-Bench, FrontierSWE, and ProgramBench across three harness–model pairs (Codex/GPT-5.5, OpenCode/DeepSeek-V4-Pro, Pi/MiniMax-M3), average relative gain is 52.25% (max 82.86%) after three iterations versus standalone harnesses. A multi-day run (>70 iterations) autonomously built a playable FPS with storyline, mechanics, visuals, and audio. Meta-harness for multi-day autonomous coding agents. https://arxiv.org/abs/2609.01481

- **CordisBench: Can Language Models Reason About Component Lifecycles in Dynamic Agent Harnesses?** — A 1,200-question benchmark on lifecycle reasoning when dynamic harnesses let models change their own execution software (dependencies, cleanup, teardown order). Tasks: identify affected components, predict state after teardown orders, determine conditions under all/some orders, choose successful reconfigurations. Models handle small systems but degrade as relevant interactions grow (2→32), especially predicting final state across teardown orders. Extra inference effort helps some models; GPT-5.6 Luna used nearly 3,000 reasoning tokens per question at medium effort on the 16-interaction subset. Independent finite reference semantics matches Cordis execution on all 528 executable scoring observations—showing cost is avoidable for controlled instances. Soft keyword miss; core harness-lifecycle reasoning. https://arxiv.org/abs/2609.01600

- **AgentFactory: Towards Automated Agentic System Design and Optimization** — Jointly searches foundation-model choices and workflow structure for agentic systems under multi-objective constraints (performance, cost, efficiency). Uses LLMs as optimizers in a three-stage pipeline that fine-tunes models and rewires workflows iteratively. Evaluation spans eight benchmarks across five domains (reasoning, coding, math, medicine, finance). Average improvement is reported as 9.1% versus manual and prior automated methods, with larger gains on MedQA (+19.6%) and FinEval (+18.7%). Directly on-topic for automated harness and workflow design rather than a single fixed agent scaffold. https://arxiv.org/abs/2609.01045

- **Calibration is the Bottleneck: An Action-Class Diagnostic of Multi-Turn Tool-Calling** — Shows aggregate tool-calling accuracy hides whether agents choose the right action class (TOOL_CALL / ASK / REFUSE / CONFIRM) versus merely failing tool execution. Introduces Acc ≤ GAR (Gold Action Recall) as a self-revealing upper bound, separating miscalibration (Acc > GAR via grader masking) from execution failure (GAR ≫ Acc). Across models and benchmarks, action-class miscalibration is a large hidden failure mode; tool-heavy training can inflate standing without context-appropriate action choice. Context-only perturbations can reshape calibration, but effects are heterogeneous (up to +11.5 vs −21.0 pp on the same scenario across families). Practical harness implication: evaluate action policy (when to call / ask / refuse / confirm), not only tool success rate. https://arxiv.org/abs/2609.00949

- **Polished but Unresolved: Identifying Late-Stage Pressure States in Long-Horizon Tool-Use Agents** — Studies late-stage “pressure” where long-horizon tool-use agents finalize with a polished answer while constraints remain unresolved. A linear probe identifies the pressure state from hidden activations; intervening along that direction changes pressure score and whether the agent keeps using tools or submits early. Constraint clarity and action mapping in context mitigate pressure. PSPR is a plugin that applies light relief under moderate pressure and structured organization under high pressure, reported to consistently strengthen existing agent methods on multiple long-horizon benchmarks. Useful harness control for premature finalization. https://arxiv.org/abs/2609.00823

- **Spawn Freely, Act Sparingly: Progressive Risk Vesting for Recursive LLM-Agent Trees** — Separates sandbox spawning (harm blocked externally) from capability activation (irreversible tool/data/code actions) in recursive LLM-agent trees. Progressive Risk Vesting (PRV) holds a trajectory-level risk budget in escrow and debits it as branches gain authority; proves an anytime harm bound under local certificates conditioned on pre-activation history. Stylized branching analysis shows trajectory harm scales differently as the authority reproduction number R_A crosses one (∝p below criticality, ∝√p at criticality, positive floor above). Design rule: search broadly in sandbox, grant recursive authority sparingly with explicit risk charges. Synthetic studies only—does not claim measured safety of deployed agents—but frames a clear harness policy for recursive tool use. https://arxiv.org/abs/2609.01035

- **Bandits in Prod: Hyperparameter Optimization at Inference Time (OHPO / IMABO)** — Formalizes Online Hyperparameter Optimization (OHPO) for production systems that can only score configs via live noisy feedback—explicitly including agentic inference choices (model, retrieval depth, prompting, temperature). IMABO pairs any bandit over already-sampled configs with any proposal oracle for new ones; IMOSS is a restart-free anytime policy with active set growing as t^β and a quantile-regret bound. Oracles tested: TPE, incumbent-mutation bandit, and a pretrained tabular foundation model, all beating uniform random. IMABO reports lowest cumulative regret across classical ML tuning and LLM-agent configuration settings. Practical for live harness knobs without a representative validation set. https://arxiv.org/abs/2609.01335

- **How to turn your AI into a world-class designer** (Lenny’s Newsletter; Anshu Chimala) — Ex-Apple AI R&D lead argues LLMs look bad at design not because they lack creativity, but because next-token training pushes them toward bland, committee-safe defaults—the purple-gradient landing page everyone gets. His fix is a Double Diamond–style agent workflow: Discover (seed-string variety via Sakana-style String Seed of Thought, plus deliberately ambitious briefs), Define (critic subagents that score screenshots against a studio quality bar, plus image/video gen to break out of code-only gradients), and Deliver (ruthlessly strip AI tells—glows, over-labels, fake custom controls). Concrete moves: generate a random alphanumeric seed outside the model so each run gets a unique aesthetic; use a strong model (e.g. Claude Fable 5) only as a fresh-context critic while a cheaper model implements; wire fal.ai video for looping graphics and scroll-scrubbed transitions (Seedance 2.5 called out for physics/consistency). Demos claim calorie trackers, space games, and landing pages in two–three prompts with Claude Opus 5 / GPT-5.6 Sol / Codex. Taste becomes a harness problem—seed injection, multi-agent critique loops, and external media tools—not a bigger base model. https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world

## Interfaces & generative video

- **Runway Solaris: Interface World Models that stream interactive UI as video** — Runway’s Solaris (Aug 31, 2026) is the first of a family it calls Interface World Models: instead of translating design into code, a real-time model synthesizes the interface frame-by-frame as the user clicks, drags, and speaks. Built by adapting Gen-4.5 for interaction and real-time (autoregressive frames, distilled few-step denoising, self-distillation for long-session stability), with an LLM deciding scene evolution while the world model renders. Pitch: fully visual apps (e.g. try-on storefronts), “alive” continuous environments, and open-ended behaviors not pre-coded as menus. Agent angle is explicit: coded UIs train computer-use agents on brittle layouts; Solaris can expose constantly changing interfaces so agents learn transferable interaction. Eval claims: multimodal LLMs (incl. Claude Fable 5) lose fidelity reconstructing screenshots as visual complexity rises; in a 250-person study (~7,500 pairwise judgments, 30 examples), Solaris beat Claude Opus 5 coded baselines—preferred 61% vs 24% for following instructions and 71% vs 21% for natural scene behavior. Limits admitted: stable real-time text, trust/grounding for commercial answers, long-session coherence, accessibility/integration. Early access via partner form. https://runway.com/news/research/introducing-solaris

- **MiniMax H3 Max / fal: realtime video unlocking interactive livestreams and gen-as-you-scroll apps** — MiniMax H3 Max, available via fal as a post-trained H3 variant tuned for prompt adherence/aesthetics and higher throughput, is fast enough that Superhuman says it can generate video faster than you watch it. fal prices image-to-video around $0.0125/s at 480p and $0.02/s at 768p.
